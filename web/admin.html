4 · Team member links

Each team member gets a personal link that shows only their own guests and gives them a sound + on-screen alert the moment one arrives. Send it on WhatsApp; they open it on their phone and tap “Enable alerts”. Anyone with a link can see that person’s guests, so share each one only with its owner.

Upload the RSVP list first — links appear for every name in the “Invited by” column.

5 · Observers (staff who watch the data)

Add the people who will view and monitor the event. Each gets a personal link that opens the live dashboard and front desk directly, with no PIN, and lets them export CSVs. They can check guests in and link walk-ins, but cannot change settings, the RSVP list or team links, reset data, or delete check-ins. Reset or remove a link at any time. Share each link only with its owner.

6 · Admin access

The admin PIN is stored (hashed) in the database. To change it, call the admin_set_pin function — see docs/SECURITY.md. Anyone with it can view the dashboard and change data — share it only with staff.

7 · Reset data

Use “Clear check-ins” after testing, before the event starts.
